# 以分叉上游 obsidian-git 为实现基础

本项目是 [Vinzent03/obsidian-git](https://github.com/Vinzent03/obsidian-git)（MIT 许可）的 fork，而不是从零实现：保留 upstream 远端并定期跟进上游更新，在此之上做完整中文化与国内网络适配。

## Considered Options

- **从零实现**：完全可控、无上游耦合，但要在 v1.0 内复刻上游十年积累的功能，工期不可接受。
- **仅参考设计、独立写代码**：介于两者之间，但没有明确收益，反而放弃直接复用上游修复。
- **分叉上游（选定）**：功能完整、上游活跃（万星级），汉化与适配工作量最小。

## Consequences

- 需要持续跟进 upstream：定期 merge 上游 release，定制改动（中文文案、国内网络适配）尽量隔离在独立文件与提交中，以减小合并冲突。
- 上游的默认行为会成为本项目默认值的基线，偏离之处需要单独记录。
