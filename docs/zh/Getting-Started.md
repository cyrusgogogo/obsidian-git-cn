# 开始使用

有两种起点：克隆现有远端仓库，或在本地初始化新仓库。

## 初始化新仓库

1. 在命令面板执行「初始化新仓库」。
2. 写点笔记，执行「同步」完成首次提交。
3. 要推送到远端（如 GitHub / Gitee）：
    1. 按[认证说明](../Authentication.zh.md)配置凭据助手。
    2. 确认远端仓库为空；否则改用「克隆」方式。
    3. 执行「推送」，按提示输入远端名称（一般填 `origin`）与仓库 URL。

## 克隆现有远端仓库

远端 URL 支持 `https` 与 `ssh`：

-   `https://github.com/<用户名>/<仓库>.git`
-   `git@github.com:<用户名>/<仓库>.git`

1. 按[认证说明](../Authentication.zh.md)配置凭据助手。
2. 命令面板执行「克隆现有远端仓库」，输入远端 URL。
3. 克隆到 Vault 根目录，或克隆到子目录后把文件（含 `.git`）移入 Vault 根。

## 推荐的默认行为

安装后默认：启动 Obsidian 时自动拉取、本地自动提交后推送、停止编辑 5 分钟后自动提交。可在设置「同步触发」中调整；「定时同步」默认关闭，开启后建议间隔 30 分钟。

## iCloud 与 Git

若用 iCloud 同步 Vault 同时在桌面端使用 Git，整个 `.git` 目录也会被同步到移动设备，可能拖慢启动。可以把 Git 仓库放在 Vault 上级目录，或把 `.git` 目录移到别处并在 Vault 里留一个只有一行 `gitdir: <实际路径>` 的 `.git` 文件。
