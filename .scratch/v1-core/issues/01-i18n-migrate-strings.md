# 迁移全部用户可见文案到 i18n

i18n 模块骨架已建（`src/i18n.ts`：英文 key、默认中文、缺失回退英文）。需要把 `src/` 与 Svelte 组件中全部用户可见文案（设置面板、命令名、通知、状态栏、弹窗、帮助文档入口）迁入翻译表并接入 `t()`。

## 验收标准

- 设置面板、命令、通知、状态栏、弹窗均经 i18n 渲染，无散落硬编码英文；
- 默认语言为中文，英文可切换；
- 设置中提供「语言：中文 / 英文」选项；
- `pnpm run tsc && pnpm run test` 通过。
