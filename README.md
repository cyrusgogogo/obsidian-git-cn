# Obsidian Git CN（中文版）

面向中文用户的 Obsidian Git 插件。目标是在 [obsidian-git](https://github.com/Vinzent03/obsidian-git)（MIT 许可）的能力基础上，提供开箱即用、界面与文档完整中文化的 Git 备份与多设备同步体验。

## 规划中的功能

- **自动提交与推送（push）**：支持手动触发、定时执行、保存后自动提交，并可选择在提交后自动推送。
- **自动拉取（pull）**：在仓库打开时或按设定间隔自动拉取远端更新。
- **远端变更检测**：检查本地与远端是否分叉、远端是否有新提交，并在状态栏或通知中提示。
- **自动合并（merge）**：拉取时优先自动合并；可配置 merge / rebase / stash 策略，冲突时给出中文提示。
- **中文界面与文档**：设置面板、命令、通知与帮助文档全部中文化。
- **国内网络环境优化**：考虑对 Gitee、HTTP 代理等常见场景的支持。

## 项目状态

项目处于**规划阶段**：当前仓库仅包含项目文档，尚未包含插件源码。

## 开发路线图

- **v0.1**：搭建 Obsidian 插件脚手架、构建与签名环境、基础设置面板
- **v0.2**：核心 Git 操作封装（commit / push / pull）
- **v0.3**：自动同步（定时、启动时、离开时）
- **v0.4**：远端变更检测、自动合并与冲突处理
- **v1.0**：完整中文化、文档、社区市场发布

## 技术方向

- TypeScript + Obsidian API
- Git 操作计划基于 simple-git（与上游 obsidian-git 一致，最终以脚手架落地为准）
